## About

I build web applications end to end — internal company systems, client sites, operation panels, and learning products — and I ship them to production myself.

- 🧠 **AI, in production, not in demos.** RAG pipelines with pgvector, LLM grading, document-to-course generation. Retrieval that cites its sources, rate limiting that survives multiple instances.
- 🎯 **Frontend focus:** performance, readability, keyboard accessibility. Next.js App Router and TypeScript are home turf.
- 🛠️ **Backend when needed:** Laravel + Inertia, PostgreSQL, Drizzle, Supabase, queue workers and schedulers.
- 🚢 **Own the deploy:** self-managed VPS with Nginx, PM2 and Let's Encrypt, plus GitHub Actions and GitLab CI → OpenShift.
- 📚 Longest-running interest: turning long lecture material into something a student can actually finish.
